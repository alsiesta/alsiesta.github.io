JavaScript Tips

Modern JavaScript Patterns

JavaScript has evolved significantly with ES6+ features. Here are some useful patterns and tips.

Destructuring

Extract values from arrays or objects easily:

// Array destructuring
const [first, second] = [1, 2, 3];

// Object destructuring
const { name, age } = { name: "Alice", age: 30 };

// Function parameter destructuring
function greet({ name, age }) {
    return `Hello ${name}, you are ${age} years old`;
}

Arrow Functions

Concise syntax for function expressions:

// Traditional function
const add = function(a, b) {
    return a + b;
};

// Arrow function
const add = (a, b) => a + b;

// With array methods
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);

Useful Array Methods

  • map() - Transform each element
  • filter() - Select elements matching a condition
  • reduce() - Reduce array to a single value
  • find() - Find first matching element
  • some() - Check if any element matches
  • every() - Check if all elements match

Examples

const users = [
    { name: "Alice", age: 30 },
    { name: "Bob", age: 25 },
    { name: "Charlie", age: 35 }
];

// Find adults
const adults = users.filter(u => u.age >= 18);

// Get names
const names = users.map(u => u.name);

// Sum ages
const totalAge = users.reduce((sum, u) => sum + u.age, 0);

Async/Await

Handle asynchronous operations cleanly:

// Async function
async function fetchData() {
    try {
        const response = await fetch('api/data');
        const data = await response.json();
        return data;
    } catch (error) {
        console.error('Error:', error);
    }
}

Template Literals

Create strings with embedded expressions:

const name = "Alice";
const age = 30;
const message = `Hello, my name is ${name} and I am ${age} years old`;

// Multi-line strings
const html = `
    <div>
        <h1>${name}</h1>
        <p>Age: ${age}</p>
    </div>
`;

Tips and Best Practices

  1. Use const by default, let when needed
  2. Avoid var - it has function scope
  3. Use strict equality === instead of ==
  4. Handle errors with try/catch blocks
  5. Use async/await for cleaner async code
