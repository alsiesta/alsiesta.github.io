Python Basics

Introduction

Python is a high-level, interpreted programming language known for its simplicity and readability. It's widely used for web development, data science, automation, and more.

Basic Syntax

Variables and Data Types

Python has several built-in data types:

  • int - Integer numbers
  • float - Decimal numbers
  • str - Text strings
  • bool - Boolean (True/False)
  • list - Ordered collection
  • dict - Key-value pairs
# Example variables
name = "Alice"
age = 30
height = 5.6
is_student = False
skills = ["Python", "JavaScript", "HTML"]

Control Flow

Python uses indentation to define code blocks:

# If statement
if age >= 18:
    print("Adult")
else:
    print("Minor")

# For loop
for skill in skills:
    print(f"I know {skill}")

# While loop
count = 0
while count < 5:
    print(count)
    count += 1

Functions

Functions are defined using the def keyword:

def greet(name):
    return f"Hello, {name}!"

# Call the function
message = greet("Alice")
print(message)  # Output: Hello, Alice!

Key Concepts

  • List Comprehensions: Concise way to create lists
  • Lambda Functions: Small anonymous functions
  • Exception Handling: Use try/except blocks
  • Modules: Import external libraries with import

Best Practices

  1. Use meaningful variable names
  2. Follow PEP 8 style guidelines
  3. Write docstrings for functions
  4. Keep functions small and focused
  5. Use virtual environments for projects
